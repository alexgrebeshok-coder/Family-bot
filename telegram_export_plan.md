# Виртуальный профиль: план работ (черновик)

## Цель
Собрать разрозненные данные (Telegram, переписки с ИИ, проекты, документы и т.д.) в единый архив, чтобы:
- понимать, чем ты занимался и к чему возвращаться;
- строить «виртуальный профиль» (интересы, проекты, люди, решения);
- быстро находить прошлые решения и контекст.

## Этап 1 — Сбор сырых данных (RAW)
### Источники
1) Telegram (группы/каналы/чаты)
2) Переписки с ИИ (OpenAI, Claude, etc.)
3) Проекты/репозитории (git)
4) Документы/ноты
5) (Опционально) календарь/почта

### Формат хранения
- JSON (минимум): id, date, sender_id, text, media_flag, reply_to
- Папки по источникам/типам

### Структура папок (пример)
```
archive/
  telegram/
    groups/
    channels/
    users/
  ai_chats/
  projects/
  docs/
  metadata/
```
