**Проблемы:**
1. OpenRouter rate limit (~20 запросов/день) — совет падал
2. ZAI тоже упал при 5 параллельных агентах
3. **ОЗУ почти всё занято** — 206MB свободно из 8GB
4. Причина зависания: 5 агентов + Codex + Notion = swap

**Решения:**
1. Запускать агентов последовательно (не параллельно)
2. Балансировать провайдеры (ZAI + OpenRouter)
3. Ограничить параллелизм до 2-3 агентов
4. Перенести на MacBook Pro M1 32GB

**Мониторинг:**
- HEARTBEAT.md обновлён — проверка памяти, rate limits, aborted sessions
- health-monitor.sh создан в workspace/ops/
- Правило: <300MB свободной памяти → НЕ запускать агентов
