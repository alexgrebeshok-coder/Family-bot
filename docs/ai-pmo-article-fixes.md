**Проблема:** 
- В статье: ROI 163%
- По формуле за 5 лет: ROI = (600 - 42.2) / 42.2 × 100% = **1322%**
- Из диплома MBA: ROI **171%** (годовой)

**Варианты решения:**

**Вариант A:** Использовать ROI из диплома MBA (более надёжный)
```markdown
ROI (годовой): 171%
Источник: Диплом MBA, PMO без AI
```

**Вариант B:** Пересчитать для 5 лет с дисконтированием
```markdown
ROI (5 лет, NPV): рассчитать с учётом ставки дисконтирования
```

**Вариант C:** Указать диапазон
```markdown
ROI: 163-394% (в зависимости от сценария)
```

**Рекомендация:** Использовать Вариант A (ROI 171% из MBA) как проверенный.

**Проблема:** Статья сразу предлагает Full внедрение за 42.2 млн.

## Альтернатива: MVP за 20-30 млн руб

**Что входит:**
- 2-3 критичных AI-агента (risk-analyzer, progress-tracker)

**Преимущества MVP:**
- Проверка гипотезы перед полным внедрением
- Минимальные риски
- Быстрый старт
