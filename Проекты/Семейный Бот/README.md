# Семейный Бот (MVP)

Ежедневный пост в семейный Telegram‑чат/канал: погода (Сургут/Тюмень/Москва), праздники, короткие новости (Сургут/Москва).

## Стек
- Python
- Groq (LLM)
- .env для секретов

## Как запустить (план)
1. Заполнить `.env` (см. `.env.example`).
2. Установить зависимости: `pip install -r requirements.txt`.
3. Запуск: `python main.py` или `python bot_dialog.py` для диалогового режима.

## Логирование

Бот ведёт детальное логирование работы в двух файлах с ротацией:

1. **Основной лог файл:** `~/Library/Logs/familybot_dialog.log`
   - Основные события: старт, входящие сообщения, отправка сообщений
   - LLM вызовы и фоллбеки (OpenRouter, ZAI)
   - Расписание чек-инов (утренние и вечерние напоминания)
   - Ошибки с детальной информацией
   - Ротация: 5MB максимум, 5 резервных копий

2. **Вспомогательный лог файл:** `/tmp/family_bot.log`
   - Дублирует основной лог (если доступна запись в /tmp)
   - Ротация: 5MB максимум, 3 резервных копии

### Что логируется:
- ✅ Старт бота
- ✅ Входящие сообщения (без чувствительных данных, только первые 50 символов)
- ✅ Отправка сообщений (только первые 30 символов текста)
- ✅ LLM вызовы (OpenRouter, ZAI) и результаты
- ✅ Локальный детект намерений (intent parsing)
- ✅ Утренние/вечерние чек-ины и родительские уведомления
- ✅ Все ошибки с full traceback

### Формат логов:
```
2026-02-21 16:30:45 | INFO | familybot_dialog | Bot starting up...
2026-02-21 16:30:46 | INFO | familybot_dialog | Received message from Иван (id=123456789): Привет, как дела?
2026-02-21 16:30:47 | INFO | familybot_dialog | Local intent detected: menu
2026-02-21 16:30:48 | INFO | familybot_dialog | Message sent (chat_id=123456789): Вот меню:
```

### Просмотр логов:
```bash
# Основной лог
tail -f ~/Library/Logs/familybot_dialog.log

# Вспомогательный лог (если доступен)
tail -f /tmp/family_bot.log

# Поиск ошибок
grep ERROR ~/Library/Logs/familybot_dialog.log
```
