# Семейный Бот (MVP)

Ежедневный пост в семейный Telegram‑чат/канал: погода (Сургут/Тюмень/Москва), праздники, короткие новости (Сургут/Москва).

## Стек
- Python
- Groq (LLM)
- .env для секретов

## Как запустить (план)
1. Заполнить `.env` (см. `.env.example`).
2. Установить зависимости: `pip install -r requirements.txt`.
3. Запуск: `python main.py`.

## Расписание
Локальный cron: 07:30 Asia/Yekaterinburg через `run_daily.sh` (с логом /tmp/family_bot.log и авто‑повтором).
