# Отчёт по добавлению логирования в семейный бот

## Что изменено

### 1. bot_dialog.py
Добавлено комплексное логирование с использованием Python `logging` и `RotatingFileHandler`:

**Импорты:**
- `import logging` - модуль логирования
- `from logging.handlers import RotatingFileHandler` - ротация логов

**Новая секция Logging Setup (строки 58-109):**
- Функция `setup_logging()` для инициализации логирования
- Основной лог файл: `~/Library/Logs/familybot_dialog.log`
- Вспомогательный лог файл: `/tmp/family_bot.log` (если доступен)
- Формат логов: `YYYY-MM-DD HH:MM:SS | LEVEL | logger_name | message`
- Ротация: 5MB максимум, 5 резервных копий (основной), 3 (вспомогательный)

**Логирование ключевых событий:**

1. **Старт бота** (строка 2220):

3. **Отправка сообщений** (строки 362, 380, 382):

   - Ошибки отправки с деталями

4. **LLM вызовы (OpenRouter)** (строки 1289-1430):
   - Запросы к API (первые 30 символов текста)
   - Успешные ответы (первые 50 символов)

   - Ошибки API

5. **LLM вызовы (ZAI)** (строки 1437-1506):
   - Запросы к API (первые 30 символов текста)
   - Успешные ответы (первые 50 символов)
   - Фоллбек на OpenRouter при ошибках

## Где логи

1. **Основной лог:** `~/Library/Logs/familybot_dialog.log`
   - Автоматически создаётся при старте бота
   - Ротация: 5MB, 5 backup файлов
   - Файлы ротации: `familybot_dialog.log.1`, `.2`, ..., `.5`

2. **Вспомогательный лог:** `/tmp/family_bot.log`
   - Создаётся, если есть права записи в /tmp
   - Ротация: 5MB, 3 backup файла
   - Если недоступен, бот продолжает работу без ошибок

## Как проверить

### 1. Запуск бота (без перезапуска по инструкции)
```bash
cd ~/".openclaw/workspace/Проекты/Семейный Бот"
python bot_dialog.py
```


## Важные примечания

1. **Безопасность данных:** В логи попадает только первые 30-50 символов текста сообщений, что исключает попадание чувствительных данных (пароли, полные сообщения с личной информацией).

2. **Ротация логов:** Лог файлы автоматически ротируются при достижении 5MB, что предотвращает переполнение диска.

3. **Обратная совместимость:** Добавление логирования не ломает существующие функции бота. Если по какой-то причине логирование недоступно (например, нет прав на запись), бот продолжит работу с использованием stderr.

4. **Временная зона:** Все логи используют Asia/Yekaterinburg (согласно настройке бота).

5. **Не запускается:** Бот не перезапускается согласно инструкции. Логирование будет активно только после ручного запуска.
